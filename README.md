GameHub is an application that allows users to manage their gaming library. Users can view over 500,000 games thanks to the integration with RAWG API which populates GameHub with data.
Users can signup to GameHub through Firebase and login to view their account page.
Users can view more details of a selected game navigating to the game details page where they can view the full game description, added content such as DLC, in game screenshots, game tags and user reviews.
Users users can also add games to their favourites page from the home page and recommendations page. From there the user can manage their games by updating the game status by to complete, to do or in progress.
The storefront page is where you can add games to your cart and proceed to checkout from there and purchase your favourite games through the help of Stripe API.
